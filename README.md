# aardwark coffee scoop (JURA-style, for ground coffee)

A replacement for the JURA measuring scoop for pre-ground coffee, with the aardwark logo on top of the handle and "Manufactured by CJ 2026" on the underside.

## Files (`output/`)

| File | What it is |
|---|---|
| `aardwark_scoop_body.stl` | The scoop. Print this file alone for a one-colour scoop. The logo is recessed 0.8 mm and the text 0.6 mm. |
| `aardwark_scoop_inlay_logo.stl` | Optional colour inlay for the logo (multi-colour printers only) |
| `aardwark_scoop_inlay_text.stl` | Optional colour inlay for the text (multi-colour printers only) |
| `aardwark_scoop.blend` | Blender scene |
| `preview_*.png`, `detail_*.png` | Renders |

## Printing

- **Orientation:** the files are already print-ready. The rim and the logo face lie on the bed with the bowl pointing up. Don't rotate them.
- **Supports:** none needed. The bowl walls overhang at most 35°, and the bowl floor is a ~19 mm bridge.
- **Size:** 185 × 47 × 20.2 mm. On a 180 mm bed (Bambu A1 mini, Prusa MINI), rotate it 45° around Z.
- **Suggested settings:** PETG or PLA, 0.2 mm layers, 4 walls (makes the 2 mm bowl wall solid), 20–25 % infill, no brim. About 20 g of filament.
- **Two colours (AMS / MMU):** drag all three STL files into the slicer at once and answer **Yes** to *"load as a single object with multiple parts?"*. Then give the two inlay parts a contrasting filament (aardwark purple is `#7350AA`). The logo colour is in the first 4 layers and the text colour in the top 3 layers of the handle.

## Use

A level scoop holds about 19.5 ml, roughly 7 g of ground coffee, the same as the JURA original. Use it for dry coffee only, and wash it by hand (PLA warps in a dishwasher).

## Changing the design

Everything is generated by `build_scoop.py`, with the parameters at the top: capacity, sizes, text and font. To rebuild:

```
blender --background --factory-startup --python build_scoop.py -- --render
blender --background --factory-startup --python verify_stl.py
```

The logo comes from the official SVG on aardwark.com (`assets/`). The ® mark is left out because it is too small to print.
